# Hiring & SOP documentation

Baseline: `docs/06-staffing.md`.

## Automate / outsource / hire decision
| Question | If yes |
|---|---|
| Rule-based and repetitive? | Automate (workflow-automation) or AI agent |
| Needs judgment but low risk, high volume? | VA with SOP + escalation rules |
| Specialist skill used part-time? | Freelancer (media buyer, Shopify dev, bookkeeper) |
| Core, continuous, strategic? | Hire (stage 3) |
| Approves spend, legal claims, disputes? | **Human owner** — never fully delegated |

## Staffing by stage
Stage 1 (< $10k/mo): founder + AI agents + automation apps. Stage 2 ($10–50k/mo): part-time VA for support/ops, freelance media buyer, UGC creators, bookkeeper. Stage 3 ($50k+/mo): full-time VAs across US hours, in-house media buyer/editor, ops manager.

## Indicative rates (2026)
PH ecommerce VA ~$5–10/h (median ~$627/mo full-time); PH customer-service VA ~$5–8/h; UGC video $100–300; freelance media buyer $500–2,000/mo or 5–10% of spend; Shopify dev $25–100/h; US bookkeeper $200–600/mo.

## Sourcing & evaluation
OnlineJobs.ph, Upwork, specialist communities. Paid trial task that mirrors the real job; check written English, response time, tool experience, references.

## SOP template
```
Title / owner / last updated
Purpose and when to use
Tools and access needed
Steps (numbered, with screenshots/links)
Decision rules and thresholds (e.g. refund ≤ $40 without approval)
Escalation: when, to whom, how
Quality check / definition of done
Metrics this SOP affects
```

## Onboarding & security
Individual staff accounts (never shared logins), least privilege, 2FA, access log, offboarding checklist that revokes all access the same day.

## Output
Role scope, decision (automate/outsource/hire), cost, job post, trial task, and SOP drafts.
