# Ad library & competitor teardown

Baseline context: `docs/04-competitors.md`.

## 1. Find competitors
- Meta Ad Library: search product keywords; note advertisers, ad start dates, number of active variants.
- TikTok Creative Center: top ads and top products in the category.
- Google Shopping and Amazon for the same item; Temu/AliExpress/Shein for the price floor.
- Established DTC brands in the niche (they set the quality bar).

## 2. Store teardown checklist (per competitor)
| Area | Capture |
|---|---|
| Offer | Price, compare-at price, bundles, quantity breaks, free-shipping threshold, guarantee |
| Shipping promise | Stated delivery time, ship-from location |
| Trust | Review count and app, UGC, policies, contact details, about page |
| Page | Hero media, headline, benefit bullets, FAQ, upsells, checkout options (Shop Pay, BNPL) |
| Brand | Name, positioning, tone, visual quality |
| Weaknesses | Slow shipping, thin reviews, poor copy, complaints (Trustpilot, Reddit, ad comments) |

## 3. Ad teardown
For each of the top 5–10 ads: hook (first 3 seconds), angle (problem/solution, before/after, unboxing, social proof, comparison), format (UGC, demo, static), CTA, offer, how long it has been running.

## 4. Price ladder
List the same or equivalent product at: marketplace floor (Temu/AliExpress), Amazon, competing Shopify stores, premium DTC brand. Our price must be justified by differentiation, not by guessing.

## 5. Output
- Competitor table (5–10 rows)
- Top hooks and angles that are working
- Price ladder and recommended price band
- **Gaps we can own** (3–5 bullets): faster shipping, better bundle, stronger guarantee, niche focus, better content
- Copying risk: how easily a competitor can clone our offer
