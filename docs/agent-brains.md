# Agent Brains & Personalities

Each agent's model (its "brain") is set with `model:` in its file in [`.claude/agents/`](../.claude/agents/). Each agent also has a first name, a voice and a working style, defined in its **Who you are** section.

## How models were chosen

| Model | Use it for | Agents |
|---|---|---|
| **opus** | Deep strategy, legal and finance judgment: decisions where a wrong call is expensive, plus coordinating and redesigning the team | 7 |
| **sonnet** | Most specialist work: research, analysis, writing, technical configuration and planning | 20 |
| **haiku** | Fast, simple lookups and template-driven tasks: support macros, rate lookups, feed checklists | 3 |

Rule of thumb: an agent gets **opus** if it makes a judgment that others rely on or that carries legal or financial risk, **haiku** if most of its tasks are quick lookups or filling templates, and **sonnet** otherwise.

## Changing a brain or personality

- Edit `model:` in the agent's file (`opus`, `sonnet`, `haiku`, `inherit`, or a full model ID), then update this table. Or ask `team-architect` (Ada) to do it.
- To cut cost, move sonnet agents to haiku for routine work; to raise quality on a hard question, ask the main session to run that expert with a stronger model, or temporarily change its `model:`.
- A subagent's `model:` applies when it is launched as a subagent. When you run `claude --agent <name>`, the agent's model is used for the whole session.
- Personalities affect tone only. Facts, output format and guardrails are the same for every agent.
- Each agent also reads its own folder in [`knowledge/`](../knowledge/README.md) before answering.
