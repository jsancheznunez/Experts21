# Knowledge — social-commerce-manager (Camila)

Documents in this folder are read by the **social-commerce-manager** agent before every answer (see [`.claude/agents/social-commerce-manager.md`](../../.claude/agents/social-commerce-manager.md)). Put the consultant's own facts here: they take priority over the general research in `docs/`.

## What belongs here
- Creator shortlist and outreach log
- Commission structures and affiliate terms
- TikTok Shop settings and performance
- Creator content and disclosure checks

## What does not belong here
- Passwords, API keys, tokens or other credentials
- Customer personal data (names, emails, addresses); summarize or anonymize instead
- General market research that every agent needs: put it in `docs/`

## Conventions
- Prefer Markdown, CSV or PDF. Name files `YYYY-MM-DD-topic.ext` so the newest is obvious.
- Put a one-line summary and the source/date at the top of each Markdown file.
- Remove or archive outdated files (`archive/` subfolder): the agent reads everything here.
